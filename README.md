Proyecto: Lista de Compras CLI 🛒

Este proyecto consiste en la implementación de una *Lista Enlazada Simple* 
utilizando Node.js, que se ejecuta a través de una interfaz de línea de comandos (CLI) interactiva.

## ⚙️ Funcionalidades
*   Añadir producto al final.
*   Listar productos enumerados.
*   Eliminar el primer elemento.
*   Buscar producto por nombre.

## 🚀 Cómo ejecutar el proyecto
1. Abrir la terminal en la carpeta del proyecto.
2. Ejecutar el comando: node index.js
